# 🌿 آیهٔ روز — Aya of the Day (v2)

ارسال خودکار روزانهٔ یک **آیهٔ منتخب از قرآن کریم** همراه با **ترجمهٔ آیت‌الله محسن قرائتی** به
**تلگرام**، **ایتا**، **روبیکا**، **بله** و **X (توییتر)**.

اجرا روی **Cloudflare Workers** با **Cron Trigger** — بدون سرور، بدون هزینه — به‌همراه یک
**داشبورد مدیریتی فارسی** روی دامنهٔ `quran.zareshahi.ir`.

</div>

## ✨ چه چیزی نسبت به نسخهٔ ۱ تغییر کرده؟

| نسخهٔ ۱ (Python/FastAPI) | نسخهٔ ۲ (این مخزن) |
| --- | --- |
| نیازمند سرور همیشه‌روشن (`uvicorn` + `schedule`) | Cloudflare Workers؛ بدون سرور و در پلن رایگان |
| فقط توییتر | تلگرام، ایتا، روبیکا، بله، X |
| زمان‌بندی داخل پروسه (با ری‌استارت از بین می‌رفت) | Cron Trigger کلادفلیر + قفل روزانه در D1 (بدون ارسال تکراری) |
| بدون رابط کاربری | داشبورد مدیریتی فارسی و راست‌چین |
| توکن‌ها در فایل `.env` | توکن‌ها رمزنگاری‌شده با AES-GCM در D1 و قابل ویرایش از داشبورد |
| آیهٔ کاملاً تصادفی + باگ بازهٔ `1..6237` | چهار حالت انتخاب آیه + بازهٔ درست `1..6236` |
| باگ در URL API (`{{...}}`) | کلاینت مقاوم با Retry و ترجمهٔ جایگزین |
| بدون گزارش | تاریخچهٔ ارسال، وضعیت تفکیکی هر کانال و لاگ |

## 🏗️ معماری

```
        ┌─────────────────────────┐
        │  Cron Trigger  */5 * * * *│
        └────────────┬────────────┘
                     ▼
  ┌──────────────────────────────────────┐
  │        Cloudflare Worker             │
  │  scheduled() ──► انتخاب آیه ──► ارسال │
  │  fetch()     ──► داشبورد + API       │
  └───────┬───────────────────┬──────────┘
          │                   │
          ▼                   ▼
   ┌─────────────┐   ┌────────────────────────────────┐
   │  D1 (SQLite)│   │ Telegram · Bale · Eitaa ·      │
   │ تنظیمات،    │   │ Rubika · X (Twitter API v2)    │
   │ کانال‌ها،    │   └────────────────────────────────┘
   │ تاریخچه، لاگ │
   └─────────────┘
```

منبع متن آیه و ترجمه: [alquran.cloud](https://alquran.cloud) — نسخهٔ عربی `quran-uthmani` و ترجمهٔ `fa.gharaati` (قرائتی).

## 🚀 راه‌اندازی سریع

```bash
git clone https://github.com/0xzare/aya-of-day-worker.git
cd aya-of-day-worker
npm install

# ۱) ساخت پایگاه‌داده
npx wrangler d1 create aya-of-day
# مقدار database_id را در wrangler.jsonc قرار دهید

# ۲) اعمال اسکیما
npx wrangler d1 execute aya-of-day --remote --file=./db/schema.sql

# ۳) تنظیم رمزها
npx wrangler secret put ADMIN_PASSWORD    # رمز ورود به داشبورد
npx wrangler secret put SESSION_SECRET    # یک رشتهٔ تصادفی بلند
npx wrangler secret put ENCRYPTION_KEY    # یک رشتهٔ تصادفی بلند

# ۴) انتشار
npx wrangler deploy
```

> برای ساخت رشتهٔ تصادفی: `openssl rand -base64 48`

## 🔑 توکن‌های کانال‌ها

هیچ توکنی داخل کد یا مخزن ذخیره نمی‌شود. همه از **داشبورد** وارد می‌شوند و رمزنگاری‌شده در D1 می‌نشینند.

| کانال | مقادیر لازم | از کجا؟ |
| --- | --- | --- |
| تلگرام | `bot_token` · `chat_id` | [@BotFather](https://t.me/BotFather) |
| بله | `bot_token` · `chat_id` | [@botfather](https://ble.ir/botfather) در بله |
| ایتا | `token` · `chat_id` | [eitaayar.ir](https://eitaayar.ir) |
| روبیکا | `bot_token` · `chat_id` | BotFather روبیکا ([مستندات](https://rubika.ir/botapi/methods)) |
| X (توییتر) | `api_key` · `api_secret` · `access_token` · `access_secret` | [developer.x.com](https://developer.x.com) با دسترسی *Read and Write* |

> ربات باید در کانال مقصد **ادمین** باشد. `chat_id` می‌تواند `@username` یا شناسهٔ عددی باشد.

## 🎛️ داشبورد مدیریتی

`https://quran.zareshahi.ir`

- **نمای کلی** — وضعیت، زمان ارسال بعدی، آخرین نتیجه
- **کانال‌ها** — فعال/غیرفعال کردن، ورود توکن، دکمهٔ «ارسال آزمایشی» برای هر کانال
- **تنظیمات** — ساعت ارسال (به‌وقت تهران)، حالت انتخاب آیه، ترجمه، هشتگ‌ها و امضا
- **تاریخچه** — آیه‌های ارسال‌شده و نتیجهٔ تفکیکی هر کانال
- **لاگ** — رویدادها و خطاها
- دکمه‌های **پیش‌نمایش** و **ارسال فوری**

## 🎲 حالت‌های انتخاب آیه

| حالت | توضیح |
| --- | --- |
| `curated` (پیش‌فرض) | چرخش روی فهرست ۱۵۰ آیهٔ منتخب و پرکاربرد |
| `random` | تصادفی اما قطعی برای هر روز (`1..6236`) |
| `sequential` | از ابتدای قرآن به‌ترتیب، با نشانگر ذخیره‌شده |
| `custom` | فهرست دلخواه شما، مثل `2:255, 3:190, 59:22` |

## 🔌 API

| مسیر | توضیح |
| --- | --- |
| `GET /health` | سلامت سرویس (عمومی) |
| `GET /api/today` | آیهٔ امروز به‌صورت JSON (عمومی) |
| `POST /api/login` | ورود به داشبورد |
| `GET /api/state` | تنظیمات + کانال‌ها + تاریخچه |
| `POST /api/settings` | ذخیرهٔ تنظیمات |
| `POST /api/channels/:id` | ذخیرهٔ تنظیمات یک کانال |
| `POST /api/test/:id` | ارسال آزمایشی به یک کانال |
| `POST /api/send-now` | ارسال فوری به همهٔ کانال‌های فعال |
| `GET /api/preview` | پیش‌نمایش پیام بدون ارسال |

## 🔒 امنیت

- ورود با رمز عبور؛ هش `PBKDF2-SHA256` با ۱۰۰٬۰۰۰ تکرار
- نشست با کوکی امضاشدهٔ `HMAC-SHA256` (`HttpOnly` · `Secure` · `SameSite=Lax`)
- توکن‌های کانال‌ها با `AES-GCM` رمزنگاری می‌شوند و در پاسخ API همیشه ماسک‌شده برمی‌گردند
- محافظت از ارسال تکراری با قفل اتمیک روزانه در D1
